# AETHERIA TAROT

เว็บแอปพลิเคชันดูดวงไพ่ยิปซีแท้ Rider-Waite 78 ใบ & ระบบเปิดไพ่ 1, 3, 10 ใบ

## การทำงาน
- Single-page application รองรับทั้ง Mobile และ Desktop
- เปิดไพ่แบบ 1 ใบ (Daily Card), 3 ใบ (Past / Present / Future), 10 ใบ (Celtic Cross)
- ค้นหาและดูความหมายไพ่ทั้ง 78 ใบ (Major Arcana & Minor Arcana) พร้อมความหมายด้านบวก ด้านกลับหัว ความรัก การงาน และการเงิน
